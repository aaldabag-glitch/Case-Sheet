## ☁️ الربط السحابي مع سوبابيس (Supabase Cloud Integration)
تم تزويد المنصة بمحرك ربط سحابي متكامل يتيح:
1. **حفظ ومزامنة حالات المرضى سحابياً** في قاعدة بيانات PostgreSQL على Supabase.
2. **العمل المشترك متعدد الأجهزة**: فتح الكيس شيت ومتابعته من الهاتف أو حاسوب العيادة.
3. **اعتماد المشرف السريري**: إرسال الحالات للاعتماد السريري سحابياً.
4. **العمل أوفلاين/محلياً**: حفظ احتياطي تلقائي في متصفح الطالب (LocalStorage) حتى في حال انقطاع الإنترنت.

### ⚙️ كيفية إعداد سوبابيس بدقيقة واحدة:
1. انقر على زر **[ سوبابيس: أوفلاين ⚙️ ]** في الشريط العلوي للمنصة.
2. ضع **Project URL** و **Public Anon Key** لمشروعك في سوبابيس.
3. اضغط على زر **[ نسخ كود إنشاء الجداول (SQL) ]**.
4. في لوحة تحكم سوبابيس، افتح **SQL Editor**، الصق الكود واضغط **Run**.
5. اضغط **[ فحص وحفظ الاتصال السحابي ]** لتتحول الإشارة إلى **سوبابيس: متصل 🟢**.

## 🚀 كيفية تشغيل التطبيق (How to Run)
1. افتح مستكشف ملفات ويندوز (Windows Explorer).
2. انتقل إلى المجلد: `C:\e-dental-casesheet\`
3. انقر نقراً مزدوجاً على الملف `index.html` ليفتح فوراً في أي متصفح حديث (Google Chrome أو Microsoft Edge).
4. أو عبر سطر أوامر PowerShell:
   ```powershell
   Start-Process "C:\e-dental-casesheet\index.html"
   ```

## 🦷 الأفرع الأكاديمية والشعب السريرية الـ 17:
1. **فرع جراحة الفم والوجه والفكين (OMFS):**
   - استمارة قلع الأسنان السريرية المعتمدة رسمياً وفق نموذج كلية القبس الأهلية (الصفحة الأولى) مع تحويل 100% من الخانات لقوائم منسدلة ذكية.
2. **فرع التشخيص الفموي (ODOM):** طب الفم، الأشعة السينية، الفحص وخطة العلاج.
3. **فرع البي أو بي (POP):** تقويم الأسنان، طب أسنان الأطفال، والوقائي.
4. **فرع صناعة الأسنان والتعويضات (PROSTH):** أطقم كاملة، جزئية، وتيجان وجسور.
5. **فرع طب الأسنان التحفظي (CONS):** حشوات ومداواة ترميمية، علاج جذور (ENDO).
